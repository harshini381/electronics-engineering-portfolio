## Antenna & RF Project

### Microstrip Patch Antenna with RCSRR for Dielectric Sensing

Worked on the design and simulation of a microstrip patch antenna integrated with a Rectangular Complementary Split Ring Resonator (RCSRR) for dielectric sensing applications.

The project investigated antenna response to different dielectric materials and analyzed frequency response and S-parameters.

Materials investigated included:

- Ethanol
- Glycerin
- NaCl
- Benzene

Tools:
- CST Studio Suite
